# Screenshots

This directory contains screenshots demonstrating the execution and functionality of the **Automated File Cleanup and Monitoring** application.

## Available Screenshots

### 1. Program Execution

Shows the application being executed from the command line with the target directory provided as an argument.

### 2. Execution Log

Shows the generated timestamped log file containing:

* Total files scanned
* Empty files found
* Files deleted
* Failed operations
* Execution time
* Execution status

### 3. Directory Cleanup

Shows the directory state before and after the cleanup operation, demonstrating the removal of empty files.

## Purpose

These screenshots provide visual evidence of the application's functionality and help demonstrate the project's execution flow and results.
