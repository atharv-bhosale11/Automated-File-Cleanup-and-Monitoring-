# Logs Directory

This directory contains log files generated by the **Automated File Cleanup and Monitoring** application.

## Purpose

The application automatically creates timestamped log files during execution to maintain a record of file-cleanup activities and execution details.

## Information Recorded

Each log file may contain:

* Deleted file paths
* Permission-related errors
* File-system errors
* Directory scanned
* Total files scanned
* Empty files detected
* Files successfully deleted
* Failed operations
* Execution time
* Execution status

## Log File Naming Convention

Log files are generated using a timestamp-based naming format:

```text
FileLog_YYYY-MM-DD_HH-MM-SS.log
```

### Example

```text
FileLog_2026-09-09_11-30-45.log
```

## Sample Summary

```text
EXECUTION SUMMARY

Directory Scanned       : Data
Total Files Scanned     : 89
Empty Files Found       : 54
Files Deleted           : 54
Files Failed            : 0
Execution Time          : 0.06 seconds
Status                  : SUCCESS
```

## Note

Log files are generated automatically when the application runs. The contents of each log file depend on the files present in the scanned directory and the actions performed during execution.
